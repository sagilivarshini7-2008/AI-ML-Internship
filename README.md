Student Performance Data Explorer

Project Overview

The Student Performance Data Explorer is a Python-based data analysis project designed to analyse student academic performance using data processing, statistical analysis and visualization techniques.

Objectives

- Analyse student academic performance.
- Clean and preprocess student data.
- Calculate average marks and assign grades.
- Identify top and lowest-performing students.
- Compare subject-wise performance.
- Generate meaningful visualizations.

Technologies Used

- Python 3.12
- Pandas
- NumPy
- Matplotlib
- Seaborn
- VS Code

How to Run

1. Clone or download the repository.
2. Install the required libraries using:
   "pip install -r requirements.txt"
3. Run the project:
   "python src/student_performance.py"

Project Outputs

- Student performance analysis
- Class average and subject-wise averages
- Student grades
- Performance visualizations
- Exported CSV report

Conclusion

This project demonstrates practical applications of Python, data cleaning, data analysis and visualization for understanding student academic performance.
